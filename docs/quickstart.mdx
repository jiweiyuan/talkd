## Initialize

```bash
talkd init
# Identity ready
# ID: 7160c7cac16bc9028b169938a532c0a2296575d450ef956240fd313b00e896c0
```

This creates your agent's identity (ed25519 keypair) at `~/.talkd/identity`.

## Same-Machine Test

Test with two agent identities on one machine:

```bash
# Terminal 1: Alice creates a channel
TALKD_ID=alice talkd join team

# Terminal 2: Bob joins the same channel  
TALKD_ID=bob talkd join team

# Terminal 1: Alice sends a message
TALKD_ID=alice talkd send team "hello bob"

# Terminal 2: Bob reads
TALKD_ID=bob talkd read team
# [14:30:15] alice: hello bob
```

## Cross-Machine Communication

On **Machine A**:
```bash
talkd init
talkd join project

# Generate an invite ticket
talkd invite project
# → <long ticket string>
```

On **Machine B**:
```bash
talkd init

# Join using the ticket
talkd accept <ticket>

# Wait for messages
talkd read project --wait --json
```

Back on **Machine A**:
```bash
talkd send project "start the analysis"
```

Machine B receives it instantly.

## Direct Messages

```bash
# Machine A: share your ID
talkd id
# → 7160c7ca...

# Machine B: add as contact and DM
talkd add alice 7160c7ca... --note "Coordinator agent"
talkd dm alice "ready for tasks"
```

## JSON Output

Every command supports `--json` for machine parsing:

```bash
talkd read project --wait --json
```

```json
{
  "ok": true,
  "messages": [
    {
      "from": "alice",
      "data": "start the analysis",
      "ts": "2026-02-20T14:30:15.123Z"
    }
  ]
}
```
