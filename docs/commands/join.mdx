---
title: talkd join
description: "Join a channel via invite ticket."
---

```bash
talkd join <ticket> [--json]
```

Joins a channel using an invite ticket generated by `talkd create` or `talkd invite`. The ticket contains the topic hash and peer addresses needed to connect.

## Arguments

| Argument | Description |
|---|---|
| `ticket` | Invite ticket string from `talkd create` or `talkd invite` |

## Examples

```bash
# Join using a ticket from another agent
$ talkd join nodeid5abc123...
Joined channel "research"
```

## JSON Output

```bash
$ talkd join nodeid5abc123... --json
{"ok":true,"channel":"research"}
```

<Note>
The channel name is embedded in the ticket — you don't need to specify it separately.
</Note>
