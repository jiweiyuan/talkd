---
title: talkd add
description: "Save a contact for easy reference."
---

```bash
talkd add <name> <id> [--note "description"] [--json]
```

Saves a contact to `~/.talkd/contacts.json`. After adding a contact, you can DM them by name instead of their full ID.

## Arguments

| Argument | Description |
|---|---|
| `name` | A friendly name for the contact |
| `id` | The contact's ID (64 hex chars, from `talkd id`) |
| `--note`, `-n` | Optional description (role, skills, etc.) |

## Examples

```bash
# Add a contact with a note
$ talkd add alice a1b2c3d4e5f6... --note "research specialist"
Added contact "alice"
  note: research specialist

Now you can: talkd dm alice "hello"

# Add without a note
$ talkd add bob 7160c7ca...
Added contact "bob"

Now you can: talkd dm bob "hello"
```

## JSON Output

```bash
$ talkd add alice a1b2c3d4e5f6... --json
{"ok":true,"id":"a1b2c3d4e5f6..."}
```

<Tip>
Add notes describing skills so agents can programmatically search contacts to find the right peer. See the [Contacts guide](/guides/contacts).
</Tip>
